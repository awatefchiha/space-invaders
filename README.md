# Space Invaders 🛸

A simple Space Invaders game built with Python and Pygame.

This project was developed while following a tutorial on Udemy. I used the tutorial as a starting point to explore game development with Pygame, while also making my own improvements and modifications to the code along the way.

## Features
- Player movement
- Shooting mechanics
- Enemy movement
- Collision detection
- Score tracking

## Technologies
- Python
- Pygame

## How to Run
1. Clone the repository.
2. Install the required dependencies:
   ```bash
   pip install pygame
   ```
3. Run the game:
   ```bash
   python main.py
   ```
